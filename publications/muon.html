Derivation of muon

We will derive Muon while gaining an intuitive understanding. We saw how Muon is more sample-efficient and even scalable in trillion-parameter models.

Look at this problem.

We know how linear transformations in neural networks happen with input \(X\) and weight \(W\).

$$Y = WX$$

Now, computing the derivative with respect to the output through the loss gives us \(G\):

$$G = \frac{\partial L}{\partial Y} X^T$$

Let's take this example, where our gradient matrix \(G\) is:

$$G = \begin{bmatrix} 7.0 & -4.0 \\ -0.07 & 0.0 \end{bmatrix}$$

Now, let's say we are updating weights with a learning rate of \(0.1\), given the weight matrix \(W\) and gradient matrix \(G\).

$$W = \begin{bmatrix} 1.0 & 2.0 \\ -1.0 & 0.5 \end{bmatrix}, \quad G = \begin{bmatrix} 7.0 & -4.0 \\ -0.07 & 0.0 \end{bmatrix}$$

If we compute the operation, we get:

$$\begin{bmatrix} W_{11}^{\text{new}} & W_{12}^{\text{new}} \\ W_{21}^{\text{new}} & W_{22}^{\text{new}} \end{bmatrix} = \begin{bmatrix} 1.0 - 0.1(7.0) & 2.0 - 0.1(-4.0) \\ -1.0 - 0.1(-0.07) & 0.5 - 0.1(0.0) \end{bmatrix}$$ $$\begin{bmatrix} W_{11}^{\text{new}} & W_{12}^{\text{new}} \\ W_{21}^{\text{new}} & W_{22}^{\text{new}} \end{bmatrix} = \begin{bmatrix} 0.3 & 2.4 \\ -0.993 & 0.5 \end{bmatrix}$$

Now look at the values. The \(W_{11}\) value moved from \(1.0\) to \(0.3\) with a huge jump, trusting this information. Similarly, \(-1.0\) moved to \(-0.993\) a microscopic crawl of \(0.007\). Almost no learning freezes it. This is the problem: if you increase the learning rate to make sure that the frozen value learns, the other large value will overshoot and divergence will occur. If you keep the learning rate small, learning will be too slow!

In gradient descent, \(G\) represents the local slope, telling us how sensitive the loss function is to a change in a specific weight at this exact micro-coordinate. Considering the slope as the distance to the minimum and then taking steep steps or crawling based on its value is somewhat misleading in compositional neural network functions.

A high gradient value means the loss is sensitive at that coordinate. Any change will bring a large difference in the output \(Y\). Taking proportional steps based on that gradient causes training to diverge; hence, we need a small step for high values. Conversely, a low gradient value means insensitivity at that coordinate: the loss will not react as strongly. This low sensitivity requires large steps. This is an inverse relationship.

This is why we don't want magnitude. We want the direction which side we should move toward, but magnitude is not useful in learning(and when we're training large models).

Adam solves this exact problem. It first solves the problem of using a fixed learning rate for all gradients by removing magnitude from the gradients.

How does it solve this? Simple: the gradient gets divided by the square root of its square:

$$\frac{7}{\sqrt{7^2}} = 1$$ $$\frac{-0.07}{\sqrt{(-0.07)^2}} = -1$$

This basically removes the magnitude of the gradient. But wait if the gradient told us to move \(7\) and we erase this learning by destroying that information, what happens? This is the question I had. We already discussed that there is an inverse relationship: a high gradient needs small steps and vice versa where direction matters over magnitude.

Look at the new weights we computed after normalization.

$$W_{\text{new}} = \begin{bmatrix} 0.9 & 2.1 \\ -0.9 & 0.5 \end{bmatrix}$$

Compare them with the unnormalized matrix:

$$\begin{bmatrix} W_{11}^{\text{new}} & W_{12}^{\text{new}} \\ W_{21}^{\text{new}} & W_{22}^{\text{new}} \end{bmatrix} = \begin{bmatrix} 0.3 & 2.4 \\ -0.993 & 0.5 \end{bmatrix}$$

The updates of the normalized matrix are now smooth.

If Adam works well, then why Muon? We saw that Adam takes each element and normalizes it before updating the entire matrix. Adam not treats a weight matrix as a unified geometric transformation, but as single scalar numbers. In a linear transformation, weights are structurally dependent on each other. Adam destroys the covariance (the mathematical relationship) between the dimensions by modifying the elements independently. Training over thousands of steps can degenerate the internal vector space of weight matrices.

Well, we derived “why Muon”, so how does it maintain this coordinate space of matrices?

Muon basically normalizes entire matrices instead of normalizing scalars. That's it.

Adam performs scalar normalization with:

$$\hat{x} = \frac{x}{\sqrt{x^2}}$$

Muon performs matrix normalization with:

$$\hat{G} = G (G^T G)^{-1/2}$$

Muon's intuition is: “When you divide a matrix by its own matrix magnitude, \(G (G^T G)^{-1/2}\), the mathematical result is an orthogonal matrix.” An interesting property of orthogonal matrices is that all their singular values are exactly \(1\). Adam makes every element \(1\); here, every singular value of the matrix is \(1\). Updating the matrix with \(\hat{G}\), which is perfectly orthogonal, acts as a pure rotation in high-dimensional space. It does not stretch, scale, or collapse the vector space; it only rotates it.

Let's derive why \(\hat{G} = G (G^T G)^{-1/2}\) is inevitable through singular value decomposition. Every matrix \(G\) can be decomposed into three parts:

$$G = U \Sigma V^T$$

(You can check this mathematical proof.)

Here, \(V\) and \(U\) are rotational matrices, and \(\Sigma\) contains the singular values that stretch and squish matrices. We need to mathematically delete \(\Sigma\) and keep \(UV^T\). This is why \(\hat{G} = G (G^T G)^{-1/2}\) is inevitable.

We need to calculate \(G^T G\) (the squared magnitude):

$$G^T G = (V \Sigma U^T) (U \Sigma V^T)$$

\(U^T U\) cancels out to the identity matrix \(I\) (as it is orthogonal).

$$G^T G = V \Sigma^2 V^T$$

But to remove sigma, we made it \(\Sigma^2\), so we neutralize it by taking the square root, \(1/2\), and then the inverse, \(\Sigma^{-1}\), as:

$$\Sigma \Sigma^{-1} = I$$

Applying \((G^T G)^{-1/2}\) gives us:

$$(G^T G)^{-1/2} = V \Sigma^{-1} V^T$$

Now, multiplying it by the original \(G\) gives:

$$G (G^T G)^{-1/2} = (U \Sigma V^T) (V \Sigma^{-1} V^T)$$

Here, \(V^T V\) cancels out to \(I\).

$$= U \Sigma \Sigma^{-1} V^T$$

Again, \(\Sigma \Sigma^{-1}\) cancels out to \(I\).

$$= U V^T$$

We just mathematically isolated and deleted the magnitude matrix \(\Sigma\), leaving only \(UV^T\) called Orthogonal Polar Factor.

Muon computationally at scale

Coming to the code, we know it's hard for computers to compute complex functions. Computing \((G^T G)^{-1/2}\) is expensive (\(O(n^3)\)). That's why we use a polynomial approximation(like taylor series) to compute this. That is the reason we use Newton-Schulz, which approximates these orthogonal matrices using only matrix multiplication(GPUs go brrrr!) instead of fully computing the SVD.

This is the code for Newton-Schulz:


X = X / (X.norm(dim=(-2, -1), keepdim=True) + 1e-7)
# Perform the NS iterations
for _ in range(steps):
    A = X @ X.mT
    B = b * A + c * A @ A  # Quintic computation strategy.
    X = a * X + B @ X

if G.size(-2) > G.size(-1):
    X = X.mT

return X

This is the derivation of the mathematical proof of this Newton-Schulz operation.
